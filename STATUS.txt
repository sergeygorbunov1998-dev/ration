РАЦИОН+ — СТАТУС СБОРКИ

Готово и проверено локально:
- iPhone PWA-интерфейс с прогресс-барами калорий/БЖУ;
- отдельные профили, настраиваемые цели, рост, вес, возраст;
- дневник питания с фотографиями, редактированием, архивом;
- тренировки фулбади, план, подходы, веса, прогресс;
- измерения, график веса, резервные копии;
- серверный код для OpenAI API, Telegram и данных виджета;
- код Scriptable-виджета для iPhone.

Пока НЕ подключено и НЕ работает без настройки владельцем:
- GitHub Pages: подключение GitHub видит публичный репозиторий, но не может записывать в него (HTTP 403, "Resource not accessible by integration"). Стандартный GitHub-коннектор ChatGPT имеет режим только чтения. Для загрузки нужен Codex с правами на запись либо ручная загрузка через GitHub.
- Сервер Cloudflare Worker не развёрнут: понадобится подключение Cloudflare, OpenAI API key (отдельная оплата), токен бота Telegram и ID канала. До этого AI и Telegram в приложении отключены.
- Виджет Scriptable надо поставить и настроить отдельно; автоматическая публикация на экран блокировки из PWA невозможна.
- Синхронизация с историей этой переписки ChatGPT не реализована, однако анализ в самом приложении поддерживается через OpenAI API после настройки сервера.

Примечание по безопасности: исходники не содержат личных данных, токенов и ключей.
